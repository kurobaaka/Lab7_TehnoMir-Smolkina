\## Описание проекта



Программа предназначена для расчёта стоимости товаров компании «ТехноМир».



Реализовано правило предоставления скидки:

\- Размер скидки составляет 20%.

\- Скидка предоставляется, если у клиента не было заказов в прошлом месяце.

\- Если заказы были, товар продаётся по полной стоимости.



\## Как запустить программу



1\. Открыть решение Visual Studio из папки `src`.

2\. Открыть проект на C#.

3\. Запустить программу клавишей F5.

4\. Посмотреть результат расчёта в консоли.



\## Пример работы



Для товара «Ноутбук» базовая стоимость составляет 50 000 рублей.



Поскольку заказов в прошлом месяце не было, применяется скидка 20%.



Итоговая стоимость: \*\*40 000 рублей\*\*.
